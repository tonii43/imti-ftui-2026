# IMTI FTUI 2026 — #MerekahMakna
Website vanilla JS (ES modules, tanpa framework). Font: Plus Jakarta Sans + Libre Baskerville (self-hosted).

```
npm install
npm run dev      # http://localhost:3000  (cek gambar: /assets-checklist)
npm run build    # hasil ke dist/
npm run assets   # buat ulang ASSETS.md + folder public/assets
```
- Gambar: letakkan di `public/assets/...` sesuai **ASSETS.md** (243 file; yang belum ada tampil sebagai bingkai placeholder).
- Link & teks: `public/js/data/site.js` (nilai `'#'` = belum diisi), data bidang: `public/js/data/bidang.js`.
- Warna: token di `public/css/base.css` (tanpa hitam murni, pakai `#011A38`).
